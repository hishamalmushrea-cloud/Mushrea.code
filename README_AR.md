## ملخص بثلاثة أسطر

أُضيف محرك مخاطر داخل التطبيق (`core/policy`) يقرر `ALLOW`/`REQUIRE_APPROVAL`/`DENY` بمنطق مستقل عن
النموذج، وآلة حالات للمهمة (`core/task`) تمنع إعلان النجاح دون فحوص وموافقة حقيقية، وقواعد استئناف/إلغاء
لا تعيد تنفيذ خطوة قد تكون وقعت، مع 76 حالة اختبار جديدة نُفِّذت فعليًا (89 اختبارًا ناجحًا مع القائمة).
لا تغيير في سلوك التطبيق الحالي، ولا APK، ولم يُدفع شيء إلى المستودع الأصلي.
